# Задача №F. Праздничная лента

## Решение

### Суть

Задача заключается в определении, можно ли из указанных слов без изменения их порядка получить ленту, такую, что между каждым из слов находится хотя бы один любой символ, выступающий в роли разделителя.

Решение - жадным образом искать вхождения слов начиная с некоторого символа. Если слово в ленте найдено, то сдвигать указатель начала просмотра ленты (с какого символа следует определять вхождение подстроки в виде слова) на длину слова и 1 символ (символ разделитель). Отсутствие слова начиная с указателя означает невозможность получения ленты.

Жадный алгоритм, заключающийся в получении индекса первого вхождения слова в ленту, работает, так как после сдвига указателя для поиска следующего слова остается максимальная лента, в которой необходимо будет найти оставшиеся слова, и требуется находить слова по порядку их поступления. В противном случае останется лента, обрезанная сначала, в которой, очевидно, в случае наличия следующего слова в обрезанной части, стоящей после первого вхождения найденного слова, следующее слово не будет найдено. 

```
/*
 * Z or prefix function:
 *
 * ababacabca
 * aba
 * ca
 *
 * [aba]bacabca -> bacabca
 * ab[aba]cabca -> cabca
 *
 * do greedy: after each deletion of word string will be longest
 */
```

При использовании наивного решения поиска подстроки асимптотика - `O(n * m)`, где `n` - длина ленты, `m` - длина максимального слова, которая не удовлетворяет требованиям ко времени решения.

Для ускорения поиска подстроки можно использовать алгоритм Кнута-Морриса-Пратта, время которого составляет `O(n + m)` для поиска в ленте слова. Алгоритм использует префикс функцию слова во время итерации.

Таким образом, решение заключается в поиске первого вхождения слова в ленте начиная с индекса `start`, смещении, в случае нахождения слова, индекса на позицию начала слова в ленте плюс длина слова плюс 1, либо, в случае ненахождения, отрицательного окончания работы программы.


### Корректность

Жадный алгоритм поиска слов в ленте работает корректно, так как слова должны идти по порядку, и после выбора первого вхождения слова и смещения индекса начала поиска на значение индекса начала слова плюс длина плюс 1 оставляет наибольшую возможную строку. В случае выбора иного слова будет вырезана большая строка из начала ленты, что может исключить вхождения каких-либо следующих слов. Пример приведен в описании сути решения. 


### Сложность

`O(n + M)`, где

- `n` - длина ленты
- `M` - сумма длин слова.

Лента просматривается только один раз, так как при нахождении слова в ленте индекс просмотра следующих слов смещается за схождением слова в ленту (лента обрезается вместе с найденным словом).

## Код

```cpp
#include <cstdint>
#include <iostream>
#include <string>
#include <vector>

template <typename T>
using V = typename std::vector<T>;

#define stdin_input() (freopen("input.txt", "r", stdin))
#define stdout_output() (freopen("output.txt", "w", stdout))

// #include "helpers.hpp"

V<size_t> prefix(const std::string& word) {
  const size_t n = word.size();
  V<size_t> p(n, 0);
  for (size_t i = 1; i < n; ++i) {
    size_t k = p[i - 1];
    while ((k > 0) && (word[i] != word[k])) {
      k = p[k - 1];
    }
    if (word[i] == word[k]) {
      ++k;
    }
    p[i] = k;
  }
  return p;
}

// if not found -> return size_max
// start - starting pos
size_t find_first_kmp(const std::string& tape, size_t start, const std::string& word) {
  size_t result = SIZE_MAX;
  auto p = prefix(word);

  size_t n = tape.size();
  size_t m = word.size();
  size_t i = start;
  size_t j = 0;

  if (start >= n) {
    return result;
  }

  while ((n - i) >= (m - j)) {
    if (word[j] == tape[i]) {
      j++;
      i++;
    }
    if (j == m) {
      result = i - j;
      break;
    } else if (i < n && word[j] != tape[i]) {
      if (j != 0) {
        j = p[j - 1];
      } else {
        i++;
      }
    }
  }

  return result;
}

int main() {
  stdin_input();
  stdout_output();

  size_t n, m;
  std::cin >> n >> m;

  std::string tape;
  std::cin >> tape;

  std::string word;
  size_t start = 0;
  bool result = true;

  for (size_t i = 0; i < m; ++i) {
    std::cin >> word;
    start = find_first_kmp(tape, start, word);
    if (start == SIZE_MAX) {
      result = false;
      break;
    }
    start += word.size() + 1;
  }

  if (result) {
    std::cout << "YES" << std::endl;
  } else {
    std::cout << "NO" << std::endl;
  }

  return 0;
}

```
