# Задача №C. Тындекс.Экспресс

## Решение

### Суть

В задании требуется реализовать класс, позволяющий выполнять операции вставки, обновления, удаления по идентификатору, а также получения `<limit>` товаров, начиная с идентификатора и `k`-ой позиции в рейтинге.

Для решения данной задачи были выбраны следующие структуры:

- `std::unordered_map` - хэш таблица, для быстрого получения элемента по идентификатору
- `AVLTree` - дерево AVL, сбалансированное по высоте двоичное дерево поиск, для получения элементов по позиции в рейтинге.

В хэш-таблице ключами выступают идентификаторы товаров, а значениями - сами объекты товаров. В AVLTree элементы отсортированы сначала по приоритету по возрастанию, а затем по идентификатору по возрастанию. Значениями дерево являются указатели на значения хэш таблицы, то есть на сами объекты.

Функция сортировки для AVL дерева выглядит следующим образом:

```cpp
template <>
inline int AVLTree<Item*>::_cmp(Item* lsv, Item* rsv) const {
  if (lsv->score == rsv->score) {
    if (lsv->id > rsv->id) {
      return 1;
    } else if (lsv->id < rsv->id) {
      return -1;
    } else {
      return 0;
    }
  } else if (lsv->score > rsv->score) {
    return 1;
  } else {
    return -1;
  }
}
```

Реализация AVL дерева соответствует типовой, которую можно получить по [<данной ссылке - ссылка>](https://habr.com/ru/articles/150732/). Дополнительно в структуру узла дерева было добавлено поле `size`, указывающее на количество узлов в данном поддереве. Это необходимо, чтобы выдавать элементы в рейтинге, начиная с некоторой позиции. Функция пересчета полей в узле `_fix` приведена ниже.

```cpp
size_t _size(AVLNode* node) const {
  return node ? node->size : 0;
}

void _fix(AVLNode* node) {
  size_t hl = _height(node->left);
  size_t hr = _height(node->right);
  node->height = (hl > hr ? hl : hr) + 1;
  size_t sl = _size(node->left);
  size_t sr = _size(node->right);
  node->size = sl + sr + 1;
}
```

Опишу реализации требуемых функций:

**Вставка**. Динамически создать новый элемент. Затем добавить элемент в хэш-таблицу по идентификатору и также вставить в AVL-дерево.

```cpp
void Add(Item item) {
  auto* itemsItem = new Item(item);
  items.emplace(item.id, itemsItem);
  avl.insert(itemsItem);
}
```

**Удаление**. Удалить элемент из AVL-дерева. Так как пара идентификатор и приоритет уникальны и гарантируется наличие этого элемента, то удалится только один элемент и дерево перестроится. После удалить элемент из хэш-таблицы и отчистить ресурсы.

```cpp
  void Remove(std::uint64_t uid) {
  auto itemsIt = items.find(uid);

  avl.remove(itemsIt->second);

  delete itemsIt->second;
  items.erase(itemsIt);
}
```

**Изменение**. Изменить элемент по идентификатору в хэш-таблице. После удалить элемент из AVL-дерева и вставить его же. Таким образом дерево снова будет отсортированным.

```cpp
void Update(Item item) {
  Item* itemsItem = items.find(item.id)->second;

  avl.remove(itemsItem);
  *itemsItem = item;
  avl.insert(itemsItem);
}
```

**Получение `<limit>` товаров, начиная с идентификатора**. Получить по указанному идентификатору указатель на элемент в хэш-таблице. Затем получить список элементов из AVL-дерева, начиная с идентификатора. Так как все элементы в дереве отсортированы, то необходимо выполнить in-order traversal по дереву для получения limit элементов.

```cpp
std::vector<uint64_t> kStLimitAtItem(const T item, size_t limit) const {
  return toVectorUint(_kstlimit(root, item, limit));
}

[[nodiscard]] std::vector<std::uint64_t> GetAtItemWithId(std::uint64_t uid, std::size_t limit)
      const {
  return avl.kStLimitAtItem(items.find(uid)->second, limit);
}
```

Говоря об in-order traversal, чтобы его выполнить начиная с указанной позиции, была разработана функция, создающая стек переходов по дереву, аналогичный как при выполнении полного обхода, на момент, как если бы текущим обрабатываемым элементом был бы `item`. Реализации функции представлена ниже. Она представляет нерекурсивный вариант обхода.

При необходимости движения налево в стек сохраняется текущий элемент (он же родитель) и осуществляется спуск налево, поскольку сравниваемый элемент меньше и в дальнейшем придется раскрутить стек до этого добавленного элемента, выбрать этот добавленный элемент и пойти в правую ветку. При проходе в правую ветку это означает, что родитель уже был обработан, поэтому в стек он не добавляется, и осуществляется переход направо. В процессе спуска до нужного элемента принцип аналогичен. Когда нужный элемент найден, то он также добавляется в стек, чтобы функция `_inorderFromStack` продолжила обход с этого элемента.

```cpp
std::vector<AVLNode*> _kstlimit(AVLNode* p, T item, size_t limit) const {
  if (p == nullptr) {
    return std::vector<AVLNode*>();
  }

  std::stack<AVLNode*> stack;

  AVLNode* cur = p;
  int c = _cmp(item, cur->key);

  if (!c) {
    stack.push(p);
  } else {
    while (c) {
      if (c < 0) {
        stack.push(cur);
        cur = cur->left;
      } else {
        cur = cur->right;
      }
      c = _cmp(item, cur->key);
    }
    stack.push(cur);
  }

  return _inorderFromStack(stack, limit);
}
```

Функция `_inorderFromStack` продолжает обход согласно стеку до тех пор пока все дерево не обойдется, либо уже было обойдено `k` элементов. Так как в прошлой функции мы добавили найденный элемент, то с него спускаться налево не нужно, поэтому устанавливается флаг `skipLeft`, чтобы дальше пойти только направо, либо раскрутиться и продолжить обычный обход. По завершении цикла возвращается список пройденных элементов.

```cpp
std::vector<AVLNode*> _inorderFromStack(std::stack<AVLNode*>& stack, size_t limit) const {
  std::vector<AVLNode*> nodes;

  size_t k = 0;
  bool skipLeft = true;
  AVLNode* cur = stack.top();

  // in-order traverse starting from k-statistics
  while (k < limit && (cur != nullptr || !stack.empty())) {
    while (!skipLeft && cur != nullptr) {
      stack.push(cur);
      cur = cur->left;
    }
    skipLeft = false;

    // current
    cur = stack.top();
    nodes.push_back(cur);
    stack.pop();
    ++k;
    cur = cur->right;
  }
  return nodes;
}
```

**Получение `<limit>` товаров, начиная с позиции**. Схожа по принципу c предыдущей, также выполняется inorder traversal, только начиная с позиции.

```cpp
std::vector<uint64_t> kStLimitAtPosition(size_t k, size_t limit) const {
  return toVectorUint(_kstlimit(root, k, limit));
}

[[nodiscard]] std::vector<std::uint64_t> GetAtPosition(std::size_t position, std::size_t limit)
    const {
  return avl.kStLimitAtPosition(position, limit);
}
```

Функция `_kstlimit` также подготавливает стек к вызову `_inorderFromStack`, однако не сравнивает элементы, а по размерам поддеревьев находит `k`-ую порядковую статистику. Кратко алгоритм следующий: если размер левого поддерева меньше необходимой ститистики, то спускаемся в это поддерево, иначе проверяем корень (размер левого поддерева + `1`) и идем в правое поддерево. Также как в прошлой реализации `_kstlimit` добавляем нужные узлы в стек. Когда нашли элемент, соответствующий `k`-ой порядковой статистике, то добавляем его в стек и вызываем функцию `_inorderFromStack`, реализация которой приведена выше.

```cpp
std::vector<AVLNode*> _kstlimit(AVLNode* p, size_t k_min, size_t limit) const {
  std::stack<AVLNode*> stack;

  // find k statistics + update stack
  size_t k = k_min + 1;
  if (p == nullptr || p->size < k) {
    return std::vector<AVLNode*>();
  }
  AVLNode* cur = p;
  while (k != 0) {
    if (cur->left && k <= cur->left->size) {
      stack.push(cur);
      cur = cur->left;
    } else {
      if (cur->left) {
        k -= cur->left->size;
      }
      k -= 1;
      if (!k) {
        stack.push(cur);
        break;
      } else {
        cur = cur->right;
      }
    }
  }

  return _inorderFromStack(stack, limit);
}
```

### Корректность

Согласно исходным требованиям к входным данным, корректности реализации `unordered_map` и AVL-дерева, программа функционирует корректно. Элементы в рейтинге, по реализации `_cmp` отсортированы по возрастанию приоритетов и идентификаторов. При удалении, изменении и добавлении элементов рейтинг пересчитывается и становится актуальным. Обход дерева для вывода `k` элементов начиная с позиции в рейтинге и идентификатора описан выше. Корректность выдаваемых результатов определяется алгоритмом реализации `k`-ой порядковой статистики по отсортированному AVL-дереву, принцип функционирования которого описан выше.

### Сложность

`O(n * log_2(n))`, где

- `n` - количество операций.

Сложность каждой функции:

- Вставка. `O(1) + O(log_2(n))`, вставка в таблицу и дерево соответственно.
- Удаление. `O(1) + O(log_2(n))`, удаление из таблицы и дерева соответственно.
- Изменениe. `O(1) + O(log_2(n))`, получение и изменение из таблицы, операция удаления и добавления - `2 * log_2(n)` в дерево соответственно.
- Получение `<limit>` товаров, начиная с позиции. `O(1) + O(log_2(n) + limit)`, получение из таблицы, спуск по дереву до нужного элемента и продолжение обхода по `<limit>` элементам соответственно.
- Получение `<limit>` товаров, начиная с идентификатора. `O(1) + O(log_2(n) + limit)`, аналогично выше.

## Код

```cpp
#pragma once

#include <cassert>
#include <cstddef>
#include <cstdint>
#include <cstdlib>
#include <iostream>
#include <stack>
#include <unordered_map>
#include <vector>

namespace youndex::express {

struct Item {
  std::uint64_t id;
  std::uint16_t score;
};

// adapted https://habr.com/ru/articles/150732/
struct AVLNode {
  Item* key;
  size_t size;  // children in subtree
  int height;   // can be stored in 1 byte (signed)
  AVLNode* left;
  AVLNode* right;

  AVLNode(Item* key) : key(key) {
    left = right = nullptr;
    height = 1;
    size = 1;
  }
};

template <typename T>
class AVLTree final {
private:
  struct AVLNode* root;

public:
  AVLTree() : root(nullptr) {
  }

  ~AVLTree() {
    traverseDelete(root);
  }

  void insert(T item) {
    this->root = _insert(root, item);
  }
  void remove(T item) {
    this->root = _remove(root, item);
  }
  std::vector<uint64_t> kStLimitAtPosition(size_t k, size_t limit) const {
    return toVectorUint(_kstlimit(root, k, limit));
  }

  std::vector<uint64_t> kStLimitAtItem(const T item, size_t limit) const {
    return toVectorUint(_kstlimit(root, item, limit));
  }

private:
  void traverseDelete(struct AVLNode* root) {
    if (root == nullptr) {
      return;
    }
    traverseDelete(root->left);
    traverseDelete(root->right);
    delete root;
  }

  std::vector<uint64_t> toVectorUint(std::vector<AVLNode*>&& nodes) const {
    std::vector<uint64_t> items;
    for (auto n : nodes) {
      items.emplace_back(n->key->id);
    }
    return items;
  }

public:
  int _cmp(const T lsv, const T rsv) const;

private:
  size_t _height(AVLNode* node) const {
    return node ? node->height : 0;
  }

  size_t _size(AVLNode* node) const {
    return node ? node->size : 0;
  }

  // signed
  int _bfactor(AVLNode* node) const {
    return _height(node->right) - _height(node->left);
  }

  void _fix(AVLNode* node) {
    size_t hl = _height(node->left);
    size_t hr = _height(node->right);
    node->height = (hl > hr ? hl : hr) + 1;
    size_t sl = _size(node->left);
    size_t sr = _size(node->right);
    node->size = sl + sr + 1;
  }

  AVLNode* _rotateright(AVLNode* p) {
    AVLNode* q = p->left;
    p->left = q->right;
    q->right = p;
    _fix(p);
    _fix(q);
    return q;
  }

  AVLNode* _rotateleft(AVLNode* q) {
    AVLNode* p = q->right;
    q->right = p->left;
    p->left = q;
    _fix(q);
    _fix(p);
    return p;
  }

  void print(AVLNode* p) const {
    std::cout << p->key->id << "+h:" << p->height;
    if (p->left) {
      std::cout << ",l:" << p->left->key->id << "+h:" << p->left->height;
    }
    if (p->right) {
      std::cout << ",r:" << p->right->key->id << "+h:" << p->right->height;
    }
    std::cout << std::endl;
  }

  AVLNode* _balance(AVLNode* p) {
    _fix(p);
    if (_bfactor(p) == 2) {
      if (_bfactor(p->right) < 0) {
        p->right = _rotateright(p->right);
      }
      return _rotateleft(p);
    }
    if (_bfactor(p) == -2) {
      if (_bfactor(p->left) > 0) {
        p->left = _rotateleft(p->left);
      }
      return _rotateright(p);
    }
    return p;
  }

  AVLNode* _insert(AVLNode* p, T k) {
    if (!p) {
      return new AVLNode(k);
    }

    int c = _cmp(k, p->key);
    if (c < 0) {
      p->left = _insert(p->left, k);
    } else {
      p->right = _insert(p->right, k);
    }
    return _balance(p);
  }

  AVLNode* _findmin(AVLNode* p) const {
    return p->left ? _findmin(p->left) : p;
  }

  AVLNode* _removemin(AVLNode* p) {
    if (p->left == nullptr) {
      return p->right;
    }
    p->left = _removemin(p->left);
    return _balance(p);
  }

  AVLNode* _remove(AVLNode* p, T k) {
    if (!p) {
      return 0;
    }

    int c = _cmp(k, p->key);
    if (c < 0) {
      p->left = _remove(p->left, k);
    } else if (c > 0) {
      p->right = _remove(p->right, k);
    } else {
      AVLNode* q = p->left;
      AVLNode* r = p->right;
      delete p;
      if (!r) {
        return q;
      }
      AVLNode* min = _findmin(r);
      min->right = _removemin(r);
      min->left = q;
      return _balance(min);
    }
    return _balance(p);
  }

  void _print_dfs(AVLNode* p, size_t depth) const {
    if (p == nullptr) {
      return;
    }
    _print_dfs(p->left, depth + 1);
    for (int i = 0; (size_t)i < depth; ++i) {
      std::cout << "  ";
    }
    std::cout << "id=" << p->key->id << ",score=" << p->key->score << ",size=" << p->size
              << std::endl;
    _print_dfs(p->right, depth + 1);
  }

  std::vector<AVLNode*> _kstlimit(AVLNode* p, size_t k_min, size_t limit) const {
    std::stack<AVLNode*> stack;

    // find k statistics + update stack
    size_t k = k_min + 1;
    if (p == nullptr || p->size < k) {
      return std::vector<AVLNode*>();
    }
    AVLNode* cur = p;
    while (k != 0) {
      if (cur->left && k <= cur->left->size) {
        stack.push(cur);
        cur = cur->left;
      } else {
        if (cur->left) {
          k -= cur->left->size;
        }
        k -= 1;
        if (!k) {
          stack.push(cur);
          break;
        } else {
          cur = cur->right;
        }
      }
    }

    return _inorderFromStack(stack, limit);
  }

  // NOTE: element should exist
  std::vector<AVLNode*> _kstlimit(AVLNode* p, T item, size_t limit) const {
    if (p == nullptr) {
      return std::vector<AVLNode*>();
    }

    std::stack<AVLNode*> stack;

    AVLNode* cur = p;
    int c = _cmp(item, cur->key);

    if (!c) {
      stack.push(p);
    } else {
      while (c) {
        if (c < 0) {
          stack.push(cur);
          cur = cur->left;
        } else {
          cur = cur->right;
        }
        c = _cmp(item, cur->key);
      }
      stack.push(cur);
    }

    return _inorderFromStack(stack, limit);
  }

  std::vector<AVLNode*> _inorderFromStack(std::stack<AVLNode*>& stack, size_t limit) const {
    std::vector<AVLNode*> nodes;

    size_t k = 0;
    bool skipLeft = true;
    AVLNode* cur = stack.top();

    // in-order traverse starting from k-statistics
    while (k < limit && (cur != nullptr || !stack.empty())) {
      while (!skipLeft && cur != nullptr) {
        stack.push(cur);
        cur = cur->left;
      }
      skipLeft = false;

      // current
      cur = stack.top();
      nodes.push_back(cur);
      stack.pop();
      ++k;
      cur = cur->right;
    }
    return nodes;
  }
};

template <>
inline int AVLTree<Item*>::_cmp(Item* lsv, Item* rsv) const {
  if (lsv->score == rsv->score) {
    if (lsv->id > rsv->id) {
      return 1;
    } else if (lsv->id < rsv->id) {
      return -1;
    } else {
      return 0;
    }
  } else if (lsv->score > rsv->score) {
    return 1;
  } else {
    return -1;
  }
}

class ItemFeed final {
private:
  AVLTree<Item*> avl;
  std::unordered_map<std::uint64_t, Item*> items;

public:
  ~ItemFeed() {
    for (auto it : items) {
      delete it.second;
    }
  }

  [[nodiscard]] std::vector<std::uint64_t> GetAtPosition(std::size_t position, std::size_t limit)
      const {
    return avl.kStLimitAtPosition(position, limit);
  }

  [[nodiscard]] std::vector<std::uint64_t> GetAtItemWithId(std::uint64_t uid, std::size_t limit)
      const {
    return avl.kStLimitAtItem(items.find(uid)->second, limit);
  }

  void Add(Item item) {
    auto* itemsItem = new Item(item);
    items.emplace(item.id, itemsItem);
    avl.insert(itemsItem);
  }

  void Update(Item item) {
    Item* itemsItem = items.find(item.id)->second;

    avl.remove(itemsItem);
    *itemsItem = item;
    avl.insert(itemsItem);
  }

  void Remove(std::uint64_t uid) {
    auto itemsIt = items.find(uid);

    avl.remove(itemsIt->second);

    delete itemsIt->second;
    items.erase(itemsIt);
  }

private:
  [[nodiscard]] bool Contains(std::uint64_t uid) const {
    return items.find(uid) != items.end();
  }

  [[nodiscard]] std::size_t Size() const {
    return items.size();
  }

};
```
