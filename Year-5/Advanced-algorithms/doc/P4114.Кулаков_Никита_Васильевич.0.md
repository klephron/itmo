# Задача №0. Квадратная строчка?

## Решение

### Суть

Считаем, что строчка квадратная до тех пор пока не встретим то, что указывает на обратное. Итеруемся по строке двумя указателями: одним с начала, вторым с середины, сравнивая символы между собой. Если символы одинаковые - продолжаем. Если символы разные - это указывает на неквадратную строку. Кроме того, при встрече строчки нечетной длины говорим, что строчка не квадратная.

### Корректность

Если строчка неквадратная, то она не может иметь четную длину, так как тогда половины различны по длине. Когда строчка имеет четную длину, значит в каких-либо позициях неквадратной строки встретились разные символы.


### Сложность

`O(n * m)`, где

- `n` - количество строк ввода
- `m` - количество символов в строке

## Код

```cpp
#include <stdio.h>
#include <string.h>

int main() {
  int n;
  scanf("%d", &n);
  while (n--) {
    char str[256];
    scanf("%s", str);
    size_t size = strlen(str);

    int res = 1;

    if (size % 2 != 0) {
      res = 0;
    }

    for (size_t i = 0, j = size / 2; i < size / 2; ++i, ++j) {
      if (str[i] != str[j]) {
        res = 0;
      }
    }

    if (res) {
      printf("YES\n");
    } else {
      printf("NO\n");
    }
  }
}
```
