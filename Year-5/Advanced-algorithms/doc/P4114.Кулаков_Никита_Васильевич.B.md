# Задача №B. Количество единиц в двоичной записи

## Решение

### Суть

Создаем целочисленный массив, соответствующий числу, размером `2 * 10e5 + 2`, так как всего `10e5` операций прибавлений чисел `1 <= 2^S <= 2^10e5`, что должно хватить. После каждой операции прибавления и вычитания числа необходимо выводить количество единиц в результирующем числе.

Изначально инициализируем массив, соответствующий числу, нулями, создаем счетчик числа единиц и инициализируем его нулем (число равно `0`). Рассмотрим операции.

При прибавлении степени двойки к числу соответствующий прибавляемому числу бит становится равным `1`, когда он был `0`, либо становится равным нулю и осуществляется перенос в старшие разряды, с которыми выполняются аналогичные операции. В результате получается цепочка операций, когда при переносе вышестоящих разрядов прибавляется степень двойки выше на одну до тех пор пока вышестоящие разряды равны `1`, в противном случае вышестоящий разряд становится равным `1` и цепочка останавливается. Таким образом, количество единиц при продолжении цепочки уменьшается на `1` до тех пор пока разряд равен `1` и увеличивается на `1` в самом конце (самый старший разряд цепочки становится равным `1`).

При вычитании числа операции выполняются обратным образом: если текущий разряд равен `0`, то выполняется займ и количество единиц увеличивается на `1` для текущего разряда до тех пор пока выполняется перенос вышестоящих разрядов, а когда в старших битах встречается `1`, то цепочка останавливается. Количество единиц изменяется аналогично: при появлении единицы - `+1`, при изменении с единицы на нуль: `-1`.

Сам алгоритм выглядит следующим образом:

```cpp
if (op == '+') {
  while (digits[s] == 1) {  // s - power of 2 of number
    digits[s] = 0;
    ones_c -= 1;
    ++s;
  }
  digits[s] = 1;
  ones_c += 1;
} else {
  while (digits[s] == 0) {
    digits[s] = 1;
    ones_c += 1;
    ++s;
  }
  digits[s] = 0;
  ones_c -= 1;
}
```

По асимптотике решение проходит.

### Корректность

Правильность вычислений обоснована правилами математических операций сложения и вычитания над целыми числами. Изменение количества единиц - зависимо от самих этих правил, поэтому вычисляется корректно.

### Сложность

`O(n * m)`, где

- `n` - количество запросов
- `m` - разрядность числа, для каждой операции бежим по индексам


## Код

```cpp
#include <cstdio>
#include <cstdlib>
#include <cstring>

#define input_open() (fopen("input.txt", "r"))
#define output_open() (fopen("output.txt", "w"))

int main() {
  FILE* input = input_open();
  FILE* output = output_open();

  int n;
  fscanf(input, "%d", &n);

  const size_t digits_l = 2 * 10e5 + 2;
  short* digits = (short*)malloc(sizeof(short) * digits_l);
  memset(digits, 0, digits_l * sizeof(short));
  size_t ones_c = 0;

  while (n--) {
    char op;
    int s;
    fscanf(input, " %c %d", &op, &s);

    if (op == '+') {
      while (digits[s] == 1) {
        digits[s] = 0;
        ones_c -= 1;
        ++s;
      }
      digits[s] = 1;
      ones_c += 1;
    } else {
      while (digits[s] == 0) {
        digits[s] = 1;
        ones_c += 1;
        ++s;
      }
      digits[s] = 0;
      ones_c -= 1;
    }

    fprintf(output, "%lu\n", ones_c);
  }

  free(digits);

  fclose(output);
  fclose(input);
}
```
