# Задача №D. Алгособес

## Решение

### Суть

Для решения данной задачи требуется быстро научиться выполнять операции попарного обмена чисел на смежных позициях и нахождения суммы на отрезке. Чтобы решить данную задачу можно воспользоваться декартовой кучей c неявным ключом. 

Поскольку обмен позиций осуществляется попарно смежно, то в каждой паре обмена участвует элемент стоящий на четной и нечетной позиции. Создадим две дерамиды, одну - для четных элементов, одну - для нечетных. При считывании распределеним элементы по дерамидам.

```cpp
for (int i = 0; i < n; ++i) {
  int v;
  scanf("%d", &v);
  if (i % 2 == 0) {
    push_back(treap_even, v);
  } else {
    push_back(treap_odd, v);
  }
}
```

Алгоритм реализации дирамид с неявным ключом следующий:

- За места ключа будем использовать `k`-ую порядковую статистику элемента. Для этого внутри дирамиды будем поддерживать поле `size`, обозначающее количество узлов в поддереве дирамиды.
- Кроме `size` также будем поддерживать сумму `sum` на поддереве.
- С помощью функции `update` обновляем значения в данном узле для `size` и `sum`.
- Функция `update` вызывается всякий раз, когда с деревом происходит операция `merge` и `split` для соответствующего поддерева дирамиды. Благодаря рекурсивному вызову данные остаются актуальными.
- Алгоритм реализации `merge` и `split` соответствует типовой реализации для декартового дерева: `merge` - все ключи правой дирамиды меньше левой, построение по приоритету, `split` - в результате два дерева, в одном все ключи меньше, оставшиеся в другом.

То есть, согласно тому, что писано выше, чтобы получать сумму на отрезке, дирамида имеет неявный ключ, соответствующий `k`-ой порядковой статистике узла, и в каждом из узлов актуализировано значение `sum` для поддерева дирамиды.

Реализация функции `sum` для получения суммы на отрезке одной дирамиды следующая:

1. Разбиваем дирамиду на 3 части при помощи последовательного вызова функций `split`: `lt` - меньше границы `l`, `gt` - больше границы `r`, `eq` - все оставшееся, то есть внутри границы. 
2. Получаем сумму на дирамиде `eq`, соответствующую сумме на отрезке.
3. Склеиваем дирамиды при помощи последовательного вызова функций `merge`.

```cpp
static long sum(Treap* self, int l, int r) {
  TreapNode *lt, *eq, *gt;
  split(self->root, l, &lt, &gt);
  split(gt, r - l + 1, &eq, &gt);
  long result = get_sum(eq);
  self->root = merge(merge(lt, eq), gt);
  return result;
}
```

Перейдем к непосредственной реализации обработчиков запросов. Рассмотрим их:

**Сумма значений между `a` и `b`**. Чтобы получить сумму необходимо получить сумму для дирамид нечетных и четных и сложить их. Из-за изменения принципа хранения элементов необходимо пересчитать границы дирамид. Для этого была реализована функция `get_bounds`, которая на основании поданных границ выдает результирующие для дирамид. Начало и конец отрезков - включительно, поэтому если левая граница больше правой, то массив пустой.

```cpp
// if s > e -> don't include
Bounds get_bounds(int l, int r) {
  int even_l, even_r;
  int odd_l, odd_r;

  l += 2;  // fix near zero bounds, (so r may be -1)
  r += 2;

  even_l = (l + 1) / 2;
  even_r = r / 2;
  odd_l = l / 2;
  odd_r = (r - 1) / 2;

  return {
      .even_l = even_l - 1,
      .even_r = even_r - 1,
      .odd_l = odd_l - 1,
      .odd_r = odd_r - 1,
  };
}
```

Алгоритм функции получения суммы на двух дирамидах:

```cpp
static long sum(Treap* even, Treap* odd, int l, int r) {
  long result = 0;

  auto bounds = get_bounds(l, r);
  if (bounds.even_l <= bounds.even_r) {
    result += sum(even, bounds.even_l, bounds.even_r);
  }
  if (bounds.odd_l <= bounds.odd_r) {
    result += sum(odd, bounds.odd_l, bounds.odd_r);
  }

  return result;
}
```

**Обмен местами парами**. Так как нечетные и четных элементы хранятся в разных дирамидах, то по принципу устройства дирамид с неявным ключом достаточно поменять местами поддеревья нечетной и четной дирамид. Рассмотрим дирамиду нечетных чисел: она состоит из частей `L1`, `M1` и `R1`, и четных: `L2`, `M2` и `R2`, где `M1` и `M2` составляют нечетные и четных элементы на отрезке, которые необходимо поменять местами. Тогда, в результате обмена должна образоваться дирамида нечетных чисел: `L1`, `M2` и `R1` и четных: `L2`, `M1` и `R2`. Реализация описываемого алгоритма приведена ниже.

```cpp
static void swap_ranges(Treap* even, Treap* odd, int l, int r) {
  Bounds bounds = get_bounds(l, r);
  swap_ranges(even, odd, bounds.even_l, bounds.even_r, bounds.odd_l, bounds.odd_r);
}
```

```cpp
//    A[a_lt .. a_eq .. a_gt] B[b_lt .. b_eq .. b_gt]
// -> A[a_lt .. b_eq .. a_gt] B[b_lt .. a_eq .. b_gt]
static void swap_ranges(Treap* a, Treap* b, int al, int ar, int bl, int br) {
  TreapNode *a_lt, *a_eq, *a_gt;
  TreapNode *b_lt, *b_eq, *b_gt;
  split(a->root, al, &a_lt, &a_gt);
  split(a_gt, ar - al + 1, &a_eq, &a_gt);
  split(b->root, bl, &b_lt, &b_gt);
  split(b_gt, br - bl + 1, &b_eq, &b_gt);

  a->root = merge(merge(a_lt, b_eq), a_gt);
  b->root = merge(merge(b_lt, a_eq), b_gt);
}
```

### Корректность

Для получения исходного массива достаточно по очереди элемент за элементом обойти нечетную и четную дирамиды с неявным ключом. Попарный обмен элементов в массиве биективен, согласно алгоритму, обмену частей декартовых деревьев, выбираемых при помощи функции `get_bounds`. 

Актуализация значений `size` и `sum`, необходимых для вычисления порядковой статистики и суммы на подотрезке, происходит через `update` каждый раз для узлов, участвующих в выполнении операций `merge` и `split`, только через которые осуществляется модификация декартового дерева. Разделение дерева происходит по порядковым статистикам, которые являются актуальными через `size`.

Операции `merge` и `split` реализованы согласно типовой реализации декартовых деревьев.

Выбор промежутков для нечетных и четных деревьев выполняется при помощи функции `get_bounds`, которая функционирует корректно на требуемых тестовых сценариях.


### Сложность

`O(R * log_2(N))`, где

- `R` - количество запросов
- `N` - количество элементов в массиве

Логарифм обусловлен случайностью построения декартовых деревьев, обеспечивающейся использованием генератора случайных чисел для задания приоритетов при построении дерева, что может с некоторой уверенностью гарантировать высоту дерева `h` ~ `log_2(N)`. Для операций нахождения суммы и обмена на отрезке используется фиксированное число корневых вызовов функций `merge` и `split`, время выполнения которых пропорционально высоте дерева.

## Код

```cpp
#include <cstdio>
#include <cstdlib>

#define stdin_input() (freopen("input.txt", "r", stdin))
#define stdout_output() (freopen("output.txt", "w", stdout))

struct TreapNode {
  int priority;
  int size;
  long value;
  long sum;
  TreapNode *left, *right;
};

struct Treap {
  TreapNode* root;
};

struct Bounds {
  int even_l;
  int even_r;
  int odd_l;
  int odd_r;
};

typedef struct Bounds Bounds;
typedef struct TreapNode TreapNode;
typedef struct Treap Treap;

static Treap* create_treap() {
  Treap* self = (Treap*)malloc(sizeof(Treap));
  Treap treap = {
      .root = NULL,
  };
  *self = treap;
  return self;
}

static TreapNode* create_node(int value) {
  TreapNode* self = (TreapNode*)malloc(sizeof(TreapNode));
  TreapNode node = {
      .priority = rand(),
      .size = 1,
      .value = value,
      .sum = value,
      .left = NULL,
      .right = NULL,
  };
  *self = node;
  return self;
}

static void delete_node(TreapNode* p) {
  if (p != NULL) {
    free(p);
  }
}

static void delete_nodes(TreapNode* p) {
  if (p != NULL) {
    delete_nodes(p->left);
    delete_nodes(p->right);
    delete_node(p);
  }
}

static void delete_treap(Treap* self) {
  if (self != NULL) {
    delete_nodes(self->root);
    free(self);
  }
}

static long get_sum(TreapNode* p) {
  return p ? p->sum : 0;
}

static int get_size(TreapNode* p) {
  return p ? p->size : 0;
}

static void update(TreapNode* p) {
  if (p != NULL) {
    p->sum = get_sum(p->left) + p->value + get_sum(p->right);
    p->size = get_size(p->left) + 1 + get_size(p->right);
  }
}

// resulting in: [lsv(keys) .. rsv(keys)]
// lsv(keys) < rsv(keys)
static TreapNode* merge(TreapNode* l, TreapNode* r) {
  if (!l || !r) {
    return l ? l : r;
  }
  if (l->priority > r->priority) {
    l->right = merge(l->right, r);
    update(l);
    return l;
  } else {
    r->left = merge(l, r->left);
    update(r);
    return r;
  }
}

// lsv(keys) < rsv(keys)
static void split(TreapNode* p, int k, TreapNode** l, TreapNode** r) {
  if (!p) {
    *l = NULL;
    *r = NULL;
  } else {
    if (get_size(p->left) < k) {
      /*
       *     lsv=p
       *  p->l p->r=a'(result of recursive call, < k)   rsv=rsv'
       */
      *l = p;
      split(p->right, k - get_size(p->left) - 1, &p->right, r);
    } else {
      *r = p;
      split(p->left, k, l, &p->left);
    }
    update(*l);
    update(*r);
  }
}

__attribute__((unused)) static int size(Treap* self) {
  return get_size(self->root);
}

static void push_back(Treap* self, int value) {
  self->root = merge(self->root, create_node(value));
}

  if (p != NULL) {

//    A[a_lt .. a_eq .. a_gt] B[b_lt .. b_eq .. b_gt]
// -> A[a_lt .. b_eq .. a_gt] B[b_lt .. a_eq .. b_gt]
static void swap_ranges(Treap* a, Treap* b, int al, int ar, int bl, int br) {
  TreapNode *a_lt, *a_eq, *a_gt;
  TreapNode *b_lt, *b_eq, *b_gt;
  split(a->root, al, &a_lt, &a_gt);
  split(a_gt, ar - al + 1, &a_eq, &a_gt);
  split(b->root, bl, &b_lt, &b_gt);
  split(b_gt, br - bl + 1, &b_eq, &b_gt);

  a->root = merge(merge(a_lt, b_eq), a_gt);
  b->root = merge(merge(b_lt, a_eq), b_gt);
}

// if s > e -> don't include
Bounds get_bounds(int l, int r) {
  int even_l, even_r;
  int odd_l, odd_r;

  l += 2;  // fix near zero bounds, (so r may be -1)
  r += 2;

  even_l = (l + 1) / 2;
  even_r = r / 2;
  odd_l = l / 2;
  odd_r = (r - 1) / 2;

  return {
      .even_l = even_l - 1,
      .even_r = even_r - 1,
      .odd_l = odd_l - 1,
      .odd_r = odd_r - 1,
  };
}

static void swap_ranges(Treap* even, Treap* odd, int l, int r) {
  Bounds bounds = get_bounds(l, r);
  swap_ranges(even, odd, bounds.even_l, bounds.even_r, bounds.odd_l, bounds.odd_r);
}

static long sum(Treap* self, int l, int r) {
  TreapNode *lt, *eq, *gt;
  split(self->root, l, &lt, &gt);
  split(gt, r - l + 1, &eq, &gt);
  long result = get_sum(eq);
  self->root = merge(merge(lt, eq), gt);
  return result;
}

static long sum(Treap* even, Treap* odd, int l, int r) {
  long result = 0;

  auto bounds = get_bounds(l, r);
  if (bounds.even_l <= bounds.even_r) {
    result += sum(even, bounds.even_l, bounds.even_r);
  }
  if (bounds.odd_l <= bounds.odd_r) {
    result += sum(odd, bounds.odd_l, bounds.odd_r);
  }

  return result;
}

int main() {
  stdin_input();
  stdout_output();

  int active = 1;
  int suite = 0;

  while (active) {
    int n, r;
    scanf("%d %d", &n, &r);

    if (n == 0 && r == 0) {
      active = 0;
      continue;
    }

    printf("Suite %d:\n", ++suite);

    Treap* treap_even = create_treap();
    Treap* treap_odd = create_treap();

    for (int i = 0; i < n; ++i) {
      int v;
      scanf("%d", &v);
      if (i % 2 == 0) {
        push_back(treap_even, v);
      } else {
        push_back(treap_odd, v);
      }
    }

    int op, a, b;
    for (int ri = 0; ri < r; ++ri) {
      scanf("%d %d %d", &op, &a, &b);
      a--, b--;

      if (op == 1)  // swap a and a+1, a+2 and a+3, ... (even length)
      {
        swap_ranges(treap_even, treap_odd, a, b);
      } else  // sum [a;b]
      {
        long result = sum(treap_even, treap_odd, a, b);
        printf("%ld\n", result);
      }
    }

    delete_treap(treap_odd);
    delete_treap(treap_even);

    printf("\n");
  }

  return 0;
}
```
