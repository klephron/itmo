# Задача №A. K-ый ноль

## Решение

### Суть

Чтобы решить данную задачу, необходимо определить, в какой позиции находится k-ый ноль на запрашиваемом отрезке. Если такового нет, то вывести `-1`. Наивный способ - при каждом запросе на получение `k`-ого нуля пробегаться по массиву и считать нули до тех пор пока не встретим `k`-ый и вывести его позицию, однако сложность такого алгоритма `O(m * n)`, что превышает рамки допустимого.

Альтернативным способом для улучшения `O` асимптотики будет воспользоваться деревом отрезков (подсчитывать в каждом узле дерева количество нулей на соответствующем узлу отрезке), что даст `O(m * log_2(n))`, либо sqrt-декомпозицией, каким способом и решена данная задача.

Заведем другой массив для подсчета количества нулей в блоках. Блок предназначен для агрегирования количества нулей на некотором отрезке длиной равной округленному вниз квадрату длины изначального массива. Согласно алгоритму получаем `(<array_length> + <block_length> - 1) / <block_length>` блоков, что приблизительно равно квадрату длины изначального массива.

После считывания изначального массива проинициализируем блоки количеством нулей на соответствующим им отрезкам. При приходе запроса на изменение элемента массива по индексу пересчитываем количество нулей в соответствующем блоке (значение изменится либо на `+1`, `-1`, `0`).

Теперь рассмотрим запрос на получение `k`-ого нуля на отрезке. Если отрезок запроса находится внутри одного блока, то требуется наивно посчитать нули в нем, так как запрашиваемый блок не полностью покрывает агрегированный результат. Если границы запроса покрывают несколько блоков - наивно посчитать первый и последний блок для запрашиваемого отрезка, так как они не покрываются полностью, а между первым и последним блоками - прибавлять агрегированный в блоках результат. Поскольку требуется найти именно `k`-ый нуль на отрезке, то если в момент подсчета было уже найдено `k` или более нулей, то мы нашли блок, в котором будет `k`-ый нуль, поэтому необходимо зайти в него и наивно найти соответствующий индекс.

Резюмируя, в данном алгоритме во время подсчета мы наивно проходимся по первому и последнему блоку и прибавляем агрегированные в блоках количества нулей. Если в момент агрегированного подсчета уже было найдено `k` или более нулей - заходим внутрь отрезка, соответствующего этому блоку, и наивно находим индекс нужного нуля. Если в заданном отрезке не встретилось нужного количество нулей (количество требуемых меньше найденных), то возвращаем `-1`.

Наивный подсчет можно вынести в отдельную функцию, которая будет возвращать индекс `k`-ого нуля, либо `-1`, если текущий номер нуля меньше, чем `k`, а также параллельно увеличивать количество пройденных нулей (в коде это функция `handle_inside`).

### Корректность

После каждого запроса пересчитывается количество единиц в блоке и обновляется исходный массив, поэтому данные всегда валидны. Значение увеличивается на `-1` - если был нуль, а стал не нуль, `0` - нуль-нeль или ненуль-ненуль, `+1` - ненуль-нуль.

Алгоритм подсчета описан выше: возвращает индекс `k`-ого нуля, параллельно считая количество пройденных нулей. 


### Сложность

`O(m * sqrt(n))`, где

- `m` - количество запросов
- `n` - количество чисел в массиве

Сложность `sqrt(n)` так как в худшем случае требуется пересчитать два блока (первый и последний, либо первый и промежуточный агрегированный), на что потребуется `sqrt(n) * 2` операций, и обойти `sqrt(n)` агрегированных блоков, получение значений из которых за `O(1)`.

Время построения блоков - `O(n)`.

Время обновления блоков - `O(1)`, так как во время изменения затрагивается только один блок.

## Код

```cpp
#include <cmath>
#include <cstdio>
#include <cstdlib>

#define input_open() (fopen("input.txt", "r"))
#define output_open() (fopen("output.txt", "w"))

static int block_i(const int i, const int bl_l) {
  return i / bl_l;
}

static int block_o(const int i, const int bl_l) {
  return i % bl_l;
}

static int handle_inside(const int* arr, int* cur_k, int k, int il, int ir) {
  int res = -1;
  for (int i = il; i <= ir; ++i) {
    if (arr[i] == 0) {
      (*cur_k) += 1;
    }
    if ((*cur_k) == k) {
      res = i;
      break;
    }
  }
  return res;
}

int main() {
  FILE* input = input_open();
  FILE* output = output_open();

  int arr_l;
  fscanf(input, "%d", &arr_l);

  int* arr = (int*)malloc(sizeof(int) * arr_l);
  for (int i = 0; i < arr_l; ++i) {
    fscanf(input, "%d", &arr[i]);
  }

  // sqrt decomposition init
  const int bl_l = sqrt(arr_l + 0.0);
  const int bl_c = (arr_l + bl_l - 1) / bl_l;
  int* bl_arr = (int*)malloc(sizeof(int) * bl_c);

  for (int i = 0; i < arr_l; ++i) {
    int bl_i = block_i(i, bl_l);
    int bl_o = block_o(i, bl_l);

    if (bl_o == 0) {
      bl_arr[bl_i] = 0;
    }
    bl_arr[bl_i] += arr[i] == 0;
  }

  int m;
  fscanf(input, "%d", &m);
  for (int op_i = 0; op_i < m; ++op_i) {
    char op;
    fscanf(input, " %c", &op);  // skip optional white space
    if (op == 'u') {
      int i, v;
      fscanf(input, "%d%d", &i, &v);
      i -= 1;

      int bl_i = block_i(i, bl_l);
      int ch = 0;
      ch -= (arr[i] == 0);
      ch += (v == 0);
      arr[i] = v;
      bl_arr[bl_i] += ch;
    } else {
      int l, r, k;
      fscanf(input, "%d%d%d", &l, &r, &k);
      l -= 1;
      r -= 1;

      const int bl_il = block_i(l, bl_l);
      const int bl_ir = block_i(r, bl_l);

      int res = -1;
      int cur_k = 0;
      do {
        if (bl_il == bl_ir) {
          res = handle_inside(arr, &cur_k, k, l, r);
        } else {
          // handle l's block
          res = handle_inside(arr, &cur_k, k, l, bl_l * (bl_il + 1) - 1);
          if (res != -1) {
            break;
          }

          // handle between
          for (int i = bl_il + 1; i < bl_ir; ++i) {
            cur_k += bl_arr[i];
            if (cur_k >= k) {
              cur_k -= bl_arr[i];
              res = handle_inside(arr, &cur_k, k, bl_l * i, bl_l * (i + 1) - 1);
              break;
            }
          }
          if (res != -1) {
            break;
          }

          // handle r's block
          res = handle_inside(arr, &cur_k, k, bl_l * bl_ir, r);
        }
      } while (0);

      if (res != -1) {
        res += 1;
      }
      fprintf(output, "%d\n", res);
    }
  }

  free(bl_arr);
  free(arr);
  fclose(input);
  fclose(output);
}
```
