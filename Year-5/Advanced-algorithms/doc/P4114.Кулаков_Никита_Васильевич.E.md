# Задача №E. Фарид и XOR такси

## Решение

### Суть

Для решения задачи необходимо найти значение максимальной скидки xor такси, получаемые при некоторых значениях `x` - номер узла, где живет он, `y` - где живет она.

Рассчитаем значения `xor` скидок путей из некоторой "корневой" вершины до остальных при помощи алгоритма DFS. Поскольку Санкт-Петербург представлен в виде дерева, то между любыми двумя вершинами существует единственный путь, поэтому и значение `xor` скидок из корневой вершины единственно.

Можно заметить, что `xor` скидка между любыми двумя вершинами соответствует `xor` скидке от корня до одной вершины `xor` скидка от корня до другой вершины, так как путь единственный и при прохождении дважды по одному пути операция `xor` зануляет результат на нем. Поскольку Фариду также необходимо проехать через узел `f`, соответствующий цветочному магазину, то здесь также можно воспользоваться предыдущими суждениями (о единственности пути и принципе работы операции `xor`), и сказать, что дважды пройденный путь занулится и останется простой путь между `x` и `y`.

Поскольку полный перебор вершин за исключением вершины `f` не проходит по асимптотике, то воспользуемся префиксным деревом для решения данной задачи. Максимальная скидка представляет из себя максимальное положительное число. Максимальное положительное число - число, у которого, если идти от старших до младших разрядов, начиная с какого-то общего будет `1`, когда как у других чисел - `0`, если, конечно, такое максимальное число единственно. 

Построим префиксное дерево от старших до младших разрядов. Благодаря нему можно быстро получить значение, при применении операции `xor` которого с некоторым `value` результат будет максимальный, что и требуется в задаче.

```cpp
void Trie::insert(uint32_t value) {
  bool inserted = false;
  Node* cur = &root;
  for (int i = (sizeof(value) * 8) - 1; i >= 0; --i) {
    int bit = (value >> i) & 1;

    Node*& next = cur->bits[bit];
    if (next == nullptr) {
      next = new Node();
      inserted = true;
    }

    cur = next;
  }
  if (inserted) {
    size += 1;
  }
}
```

Для нахождения максимального числа, согласно описанному ранее, каждый раз будем брать от старшего разряда бит, противоположный в этой же позиции `value`. Если же в префиксном дереве нет такого элемента, то берем какой есть. Таким образом на каждом шаге обеспечивается максимизацию результата.

```cpp
uint32_t xorMax(uint32_t value) {
  Node* cur = &root;
  int32_t result = 0;
  for (int i = (sizeof(value) * 8) - 1; i >= 0; --i) {
    int bit = (value >> i) & 1;
    if (cur->bits[1 - bit]) {
      cur = cur->bits[1 - bit];
      result ^= ((1 - bit) << i);
    } else {
      cur = cur->bits[bit];
      result ^= (bit << i);
    }
  }
  return result;
}
```

Таким образом, весь алгоритм сводится к построению префиксного дерева, для некоторого `x` нахождения `value` (пути `y`), при примении с `x` дающего максимальный результат. Вершину `f` включать не следует, так как `x != f && y != f`. Насчет `x` не переживаем, так как при применении на самого себя получается минимальная скидка. Ниже приведена это демонстрирующая часть кода:

```cpp
dfs(edges, root_xors, visited, 0);

for (size_t i = 0; i < root_xors.size(); ++i) {
  if (i != f) {
    trie.insert(root_xors[i]);
  }
}

uint32_t xor_max = 0;
for (uint32_t i = 1; i < n; ++i) {
  if (i != f) {
    xor_max = std::max(xor_max, trie.xorMax(root_xors[i]) ^ root_xors[i]);
  }
}

std::cout << xor_max << std::endl;
```



### Корректность

Очевидно, что максимально то положительное число, у которого в бинарном представлении если идти от старшего разряда к младшему в первом таком `i` стоит `1`, а у другого `0`.

Очевидно, что `xor` двух чисел максимален, если в результате получается максимальное положительное число, а для этого начиная от старшего разряда, если зафиксировать одно число, следует брать то, у которого иной бит в самом старшем разряде, потому что `0 xor 0 = 0`, `1 xor 1 = 0`, `1 xor 0 = 1`.

`xor` пути между любыми двумя вершинами в дереве равен `xor` пути от некоторой вершины до одной и от некоторой вершины до другой, так как путь между любыми двумя вершинами единственен и в результате операции `xor` образуется простой путь (значение, соответствующее простому пути между этими вершинами), а он в дереве как раз тоже единственен. То есть неважно, возьмем ли мы вершину `f` или случайную и посчитаем `xor` от этой вершины до `x` и `y`, все равно после `xor` образуется простой путь между `x` и `y`.

### Сложность

`O(n * k)`, где

- `n` - количество вершин
- `k` - количество разрядов в числе

Для каждого запроса необходимо пройти `k` вершин в префиксном дереве.

Время заполнения префиксного дерева - `O(n * k)`.

## Код

```cpp
#include <cstdint>
#include <iostream>
#include <list>
#include <vector>

using LPII = typename std::list<std::pair<int32_t, int32_t>>;

template <typename T>
using V = typename std::vector<T>;

#define stdin_input() (freopen("input.txt", "r", stdin))
#define stdout_output() (freopen("output.txt", "w", stdout))

class Trie {
private:
  struct Node {
    Node* bits[2] = {0};
  } root;
  uint32_t size = 0;

public:
  ~Trie() {
    deleteNodes(root.bits[0]);
    deleteNodes(root.bits[1]);
  }

  void insert(uint32_t value) {
    bool inserted = false;
    Node* cur = &root;
    for (int i = (sizeof(value) * 8) - 1; i >= 0; --i) {
      int bit = (value >> i) & 1;

      Node*& next = cur->bits[bit];
      if (next == nullptr) {
        next = new Node();
        inserted = true;
      }

      cur = next;
    }
    if (inserted) {
      size += 1;
    }
  }

  uint32_t xorMax(uint32_t value) {
    Node* cur = &root;
    int32_t result = 0;
    for (int i = (sizeof(value) * 8) - 1; i >= 0; --i) {
      int bit = (value >> i) & 1;
      if (cur->bits[1 - bit]) {
        cur = cur->bits[1 - bit];
        result ^= ((1 - bit) << i);
      } else {
        cur = cur->bits[bit];
        result ^= (bit << i);
      }
    }
    return result;
  }

  void print() {
    std::cout << "size: " << size << std::endl;
    if (size != 0) {
      printNodes(&root, 0, 0);
    }
  }

private:
  void printNodes(Node* cur, int l, uint32_t prefix) {
    if (cur == nullptr) {
      return;
    }
    for (int i = 0; i < l; ++i) {
      std::cout << " ";
    }
    std::cout << cur;
    if (cur->bits[0] == nullptr && cur->bits[1] == nullptr) {
      std::cout << " - " << prefix << std::endl;
    } else {
      std::cout << std::endl;
    }
    printNodes(cur->bits[0], l + 1, (prefix << 1) | 0);
    printNodes(cur->bits[1], l + 1, (prefix << 1) | 1);
  }

  void deleteNodes(Node* cur) {
    if (cur == nullptr) {
      return;
    }
    deleteNodes(cur->bits[0]);
    deleteNodes(cur->bits[1]);
    delete cur;
  }
};

void dfs(const V<LPII>& edges, V<int32_t>& root_xors, V<bool>& visited, const int32_t i) {
  visited[i] = 1;
  for (const auto& [j, w] : edges[i]) {
    if (visited[j] == false) {
      root_xors[j] = root_xors[i] ^ w;
      dfs(edges, root_xors, visited, j);
    }
  }
}

int main() {
  stdin_input();
  stdout_output();

  uint32_t n, f;

  std::cin >> n >> f;
  --f;

  V<int32_t> root_xors(n, 0);
  V<bool> visited(n, 0);
  V<LPII> edges(n, LPII());
  Trie trie;

  int32_t u, v, w;
  for (uint32_t i = 0; i < n - 1; ++i) {
    std::cin >> u >> v >> w;
    --u, --v;
    edges[u].push_back(std::make_pair(v, w));
    edges[v].push_back(std::make_pair(u, w));
  }

  dfs(edges, root_xors, visited, 0);

  for (size_t i = 0; i < root_xors.size(); ++i) {
    if (i != f) {
      trie.insert(root_xors[i]);
    }
  }

  uint32_t xor_max = 0;
  for (uint32_t i = 1; i < n; ++i) {
    if (i != f) {
      xor_max = std::max(xor_max, trie.xorMax(root_xors[i]) ^ root_xors[i]);
    }
  }

  std::cout << xor_max << std::endl;

  return 0;
}
```
