# Задача №H. Темпоральный катаклизм

## Решение

### Суть

Временные реальности переплетаются в структуру, которая является деревом, по условию задачи. Решение задачи можно свести к нахождению минимального расстояния (далее кратчайший путь) между двумя узлами дерева, чтобы затем, сравнивая с данным значением "энергии" определить, является ли полученный результат меньшим, либо равным значению "энергии". Если данное условие выполняется, то вывести "Yes", иначе "No".

Кратчайший путь на дереве между двумя вершинами - такой путь, который не проходит одну и ту же вершину дважды (это единственный случай, так как на дереве нет циклов), и не проходит ребро в обе стороны. Когда ребро проходится в обе стороны, то длина пути увеличивается на 2, поэтому путь не является кратчайшим. Чтобы найти кратчайший путь можно сделать XOR по ребрам (как в задаче о Фариде и его девушке).

Таким образом, минимальное количество энергии, которое нужно потратить, чтобы перейти из одной вершины в другую - кратчайший путь на дереве. Поскольку на дереве нет циклов, то такой кратчайший путь должен будет пройти через LCA (Lowest Common Ancestor). LCA, так как если выбрать вершину выше, то необходимо будет спуститься, а потом подняться, что значит пройти одно и то же ребро в обе стороны, а это не кратчайший путь.

Теперь опишу непосредственно алгоритм решения:

1. Считать список ребер и построить дерево.
2. На каждый запрос вычислять LCA и сравнивать с данным количеством энергии. Если меньше - output "No", в противном случае "Yes".

Так как при считывании ребер не дается, какая вершина является родителем и ребенком, то сначала я буферизировал ребра, добавляя их к двусторонним связям узлов, а после этого запускал по графу DFS и превращал граф в дерево (он изначально без циклов, но я это делал, чтобы сформировать вектор с векторами детей вершины).

В качестве вершины, с которой стартует алгоритм DFS я выбрал нулевую, так как не важно, за какую вершину подвешивать дерево.

Сам граф является связным, поэтому будут обойдены все вершины.

В результате был построен вектор векторов детей, где индекс - номер вершины, а значение (сам вектор) - список его детей.

```cpp
V<V<int32_t>> tree_children;

void tree_children_build_dfs(int32_t p) {
  visited[p] = 1;
  for (auto c : edges[p]) {
    if (!visited[c]) {
      tree_children[p].emplace_back(c);
      tree_children_build_dfs(c);
    }
  }
}
```

Количество необходимой энергии - длина пути, а значит равна расстоянию от вершины `l` до `lca` прибавить расстояние от `lca` к `r`, что тоже самое, что и разность высот вершин `l` и `lca` прибавить `r` и `lca`, так как граф - дерево, и по пути мы сначала поднимаемся, каждый раз уменьшая высоту на единицу, а затем от `lca` спускаемся.

Наивный способ найти глубину, LCA и посчитать высоты вершин потребует `O(h^2)` времени, так как при поднятии каждая с каждой сравнивается на `lca` и необходимо посчитать высоту самой вершины `O(n)`, что для этого кроме того требует хранить список родителей вершин.

Другим способом нахождения `lca` является использование дерева отрезков или sparse-table. Для этого нужно сначала представить дерево в линейном формате. Это можно сделать за `O(n)`, делая BFS in-order traversal, при этом при попадании в вершину делать `push_back` в массив пройденных вершин, составляя массив `nodes` с пройденными вершинами. Также параллельно вычислять массив `depths`, как и `nodes` с глубинами вершин, зная, что рекурсивно спуская глубина увеличивается на единицу, а поднимаясь - уменьшается. Чтобы не делать `push_back` я вычисляю по ходу индекс в массиве `nodes` и возвращаю из функции `lca_setup_dfs` значение, соответствующее этому индексу (индекс показывает на следующий элемент).

Чтобы быстро сделать маппинг глубин и самих вершин, необходимо оббегать массив `depths` и `nodes`. Чтобы этого не делать, я завел массив `lasts`, где индекс - сам индекс вершины, а значение - индекс его последнего вхождения в массивы `depths` и `nodes`. Таким образом, чтобы быстро сделать соответствие, можно воспользоваться `lasts`. Длины массива `depths` и `nodes` - `2 * N - 1`, а `lasts` - `N`, где `N` - массивы вершин. Листинг данных вычислений представлен ниже.

```cpp
static int32_t lca_setup_dfs(int32_t d, int32_t i, int32_t p) {
  nodes[i] = p;
  depths[i] = d;
  for (auto ch : tree_children[p]) {
    i = lca_setup_dfs(d + 1, i + 1, ch);
    nodes[i] = p;
    depths[i] = d;
  }
  lasts[p] = i;
  return i + 1;
}
```

Вернемся к sparse-table и segment-tree. После того, как были получены массивы `depths` и `nodes`, `depths` можно занести в sparse-table и segment-tree как RMQ. После этого через `lasts` получить отрезок, сделать запрос в эти структуры для нахождения минимальной глубины, соответствующей как раз LCA, потому что вершина с минимальной глубиной является общим предком по построению алгоритма, плюс она также является LCA, а не его предком, так как иначе бы мы по ходу алгоритма поднялись и больше не вернулись, верно по построению. Таким образом, это именно LCA.

Чтобы в sparse-table и segment-tree не делать проверки, что правая граница меньше либо равна левой, я делаю вот это:

```cpp
int32_t la = lasts[a];
int32_t lb = lasts[b];

int32_t l = std::min(la, lb);
int32_t r = std::max(la, lb);
```

В итоге выполняя Ranged Queries по sparse-table и segment-tree мы можем получить высоту вершины, соответствующей LCA. Далее через массив `lasts` можно получить индекс элемента в массиве `depths`, соответствущей высоте самой вершины. Таким образом получаем высоты детей, а далее вычисляем длину пути (почему это тоже самое, что и разность высот, описано выше):

```cpp
return l_depth + r_depth - 2 * ca_depth;
```

Как можно заметить, массив `nodes` нигде не используется, поэтому его можно не вычислять (остался в решении, так как раньше в segment-tree находились не сами высоты, а индексы вершин, а для сравнения выполнялись обращения в массив `depths`).

Алгоритмы для реализации sparse-table и segment-tree типовые, доказательство их правильности работы здесь не привожу.

P.S. также предпосчитал для sparse-table логарифмы в массиве `logarithms`.

### Корректность

Выше по ходу повествования доказана корректность:
- построения дерева, по которому выполняется LCA
- построения массивов `nodes` и `last`
- эквивалентность понятия вершины на отрезке `depths` и минимальной глубиной и LCA
- эквивалентность длины пути и разности высот от вершины до LCA и до другой вершины

### Сложность

Для sparse-table:
- по времени `O(N*log2(N) + Q)`, где
- по памяти `O(N*log2(N))`

Для segment-tree:
- по времени `O(N + Q*log2(N))`
- по памяти `O(N)`

Другое (по времени):
1. Построение дерева детей через BFS - `O(N)`, так как в дереве N-1 ребро.
2. Препроцессинг sparse-table: `O(N*log2(N))`
3. Препроцессинг segment-tree: `O(N)`

Другое (память):
1. sparse-table: `O(N*log2(N))`
2. segment-tree: `O(N)`
3. дерево детей: `O(N)`
4. прочие массивы `nodes`, `depths`, `logarithms` (предпосчитанные логарифмы), `lasts`: `O(N)`

## Код

Две реализации.

Таблица (`sparse-table`):

```cpp
#include <climits>
#include <cmath>
#include <cstdio>
#include <iostream>
#include <vector>

#define stdin_input() (freopen("input.txt", "r", stdin))
#define stdout_output() (freopen("output.txt", "w", stdout))

template <typename T>
using V = typename std::vector<T>;

#define LCA_SIZE 200000
#define NODES_SIZE 100000
#define SPT_LOG 18

V<V<int32_t>> edges;
int32_t visited[NODES_SIZE];

V<V<int32_t>> tree_children;
int32_t depths[LCA_SIZE];
int32_t nodes[LCA_SIZE];
int32_t lasts[NODES_SIZE];
int32_t sp_table[LCA_SIZE][SPT_LOG];
int32_t logs2[LCA_SIZE];

// returns next i
static int32_t lca_setup_dfs(int32_t d, int32_t i, int32_t p) {
  nodes[i] = p;
  depths[i] = d;
  for (auto ch : tree_children[p]) {
    i = lca_setup_dfs(d + 1, i + 1, ch);
    nodes[i] = p;
    depths[i] = d;
  }
  lasts[p] = i;
  return i + 1;
}

static void sparse_table_min_build(int32_t n) {
  int32_t log_v = 0;
  int32_t next_log_i = 2;

  for (int32_t i = 0; i < n; ++i) {
    sp_table[i][0] = depths[i];
    if (i == next_log_i) {
      next_log_i *= 2;
      ++log_v;
    }
    logs2[i] = log_v;
  }

  for (int32_t j = 1; j < SPT_LOG; ++j) {
    for (int32_t i = 0; i + (1 << j) - 1 < n; ++i) {
      sp_table[i][j] = std::min(sp_table[i][j - 1], sp_table[i + (1 << (j - 1))][j - 1]);
    }
  }
}

static inline int32_t energy_required(int32_t a, int32_t b) {
  int32_t la = lasts[a];
  int32_t lb = lasts[b];

  int32_t l = std::min(la, lb);
  int32_t r = std::max(la, lb);

  int32_t size = r - l + 1;
  int32_t log = logs2[size];
  int32_t query_l = sp_table[l][log];
  int32_t query_r = sp_table[r - (1 << log) + 1][log];
  int32_t ca_depth = query_l < query_r ? query_l : query_r;

  int32_t l_depth = depths[la];
  int32_t r_depth = depths[lb];
  return l_depth + r_depth - 2 * ca_depth;
}

void tree_children_build_dfs(int32_t p) {
  visited[p] = 1;
  for (auto c : edges[p]) {
    if (!visited[c]) {
      tree_children[p].emplace_back(c);
      tree_children_build_dfs(c);
    }
  }
}

void tree_children_build() {
  int32_t n = edges.size();
  tree_children = std::vector<V<int32_t>>(n);

  for (int32_t i = 0; i < n; ++i) {
    visited[i] = 0;
  }
  tree_children_build_dfs(0);
}

int main() {
  stdin_input();
  // stdout_output();
  std::ios_base::sync_with_stdio(false);
  std::cin.tie(nullptr);

  int32_t n, q;

  std::cin >> n;
  int32_t size = n;

  edges = std::vector<V<int32_t>>(size);
  while (--n) {
    int32_t u, v;
    std::cin >> u >> v;

    edges[u].emplace_back(v);
    edges[v].emplace_back(u);
  }

  tree_children_build();

  lca_setup_dfs(0, 0, 0);

  sparse_table_min_build(size * 2 - 1);

  std::cin >> q;
  while (q--) {
    int32_t u, v, t;
    std::cin >> u >> v >> t;

    int32_t req = energy_required(u, v);
    bool ok = (req <= t);

    if (ok) {
      std::cout << "Yes\n";
    } else {
      std::cout << "No\n";
    }
  }
}
```

Сегментное дерево (`segment-tree`):

```cpp
#include <climits>
#include <cstdio>
#include <iostream>
#include <vector>

#define stdin_input() (freopen("input.txt", "r", stdin))
#define stdout_output() (freopen("output.txt", "w", stdout))

template <typename T>
using V = typename std::vector<T>;

const size_t LCA_SIZE = 200000;
const size_t NODES_SIZE = 100000;
const size_t TREE_SIZE = 1 << 19;

V<V<int32_t>> edges;
int32_t visited[NODES_SIZE];

V<V<int32_t>> tree_children;
int32_t depths[LCA_SIZE];
int32_t lasts[NODES_SIZE];

int32_t depth_tree[TREE_SIZE];

static int32_t seg_tree_query(int32_t i, int32_t tl, int32_t tr, const int32_t l, const int32_t r) {
  if (l <= tl && tr <= r) {
    return depth_tree[i];
  } else if (tr < l || tl > r) {
    return INT_MAX;
  } else {
    int32_t mid = tl + (tr - tl) / 2;
    int32_t left_i = seg_tree_query(2 * i + 1, tl, mid, l, r);
    int32_t right_i = seg_tree_query(2 * i + 2, mid + 1, tr, l, r);
    return left_i < right_i ? left_i : right_i;
  }
}

static inline void seg_tree_build(size_t n) {
  size_t ti = (TREE_SIZE / 2 - 1);
  for (size_t i = 0; i < n; ++i, ++ti) {
    depth_tree[ti] = depths[i];
  }
  for (; ti < TREE_SIZE; ++ti) {
    depth_tree[ti] = INT_MAX;
  }
  for (ti = (TREE_SIZE / 2) - 2;; --ti) {
    int32_t left_i = depth_tree[2 * ti + 1];
    int32_t right_i = depth_tree[2 * ti + 2];
    depth_tree[ti] = left_i < right_i ? left_i : right_i;
    if (ti == 0)
      break;
  }
}

// returns next i
static int32_t lca_setup_dfs(int32_t d, int32_t i, int32_t p) {
  depths[i] = d;
  for (auto ch : tree_children[p]) {
    i = lca_setup_dfs(d + 1, i + 1, ch);
    depths[i] = d;
  }
  lasts[p] = i;
  return i + 1;
}

static inline void children_build_dfs(int32_t p) {
  visited[p] = 1;
  for (auto c : edges[p]) {
    if (!visited[c]) {
      tree_children[p].push_back(c);
      children_build_dfs(c);
    }
  }
}

static inline void children_build() {
  size_t n = edges.size();
  tree_children = std::vector<V<int32_t>>(n);

  for (size_t i = 0; i < NODES_SIZE; ++i) {
    visited[i] = 0;
  }

  children_build_dfs(0);
}

static inline int32_t energy_required(int32_t l, int32_t r) {
  int32_t last_l = lasts[l];
  int32_t last_r = lasts[r];

  int32_t ll = std::min(last_l, last_r);
  int32_t lr = std::max(last_l, last_r);

  int32_t ca_depth = seg_tree_query(0, 0, TREE_SIZE / 2 - 1, ll, lr);

  int32_t l_depth = depths[last_l];
  int32_t r_depth = depths[last_r];
  return l_depth + r_depth - 2 * ca_depth;
}

int main() {
  stdin_input();
  // stdout_output();
  std::ios_base::sync_with_stdio(false);
  std::cin.tie(nullptr);

  int32_t n, q;

  std::cin >> n;
  int32_t size = n;

  edges = std::vector<V<int32_t>>(n);
  while (--n) {
    int32_t u, v;
    std::cin >> u >> v;

    edges[u].emplace_back(v);
    edges[v].emplace_back(u);
  }

  children_build();
  lca_setup_dfs(0, 0, 0);
  seg_tree_build(size * 2 - 1);

  std::cin >> q;
  while (q--) {
    int32_t u, v, t;
    std::cin >> u >> v >> t;

    int32_t req = energy_required(u, v);

    if (req <= t) {
      std::cout << "Yes\n";
    } else {
      std::cout << "No\n";
    }
  }
}
```
