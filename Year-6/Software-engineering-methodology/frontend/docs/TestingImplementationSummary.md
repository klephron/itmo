## 🛠️ Технические особенности

### Кастомные команды Cypress

Реализованы следующие кастомные команды в `cypress/support/commands.ts`:

1. **cy.login(username, password)** - Авторизация пользователя
2. **cy.fillIncidentForm(data)** - Заполнение формы инцидента
3. **cy.fillCaseForm(data)** - Заполнение формы дела
4. **cy.fillClueForm(data)** - Заполнение формы улики
5. **cy.createIncidentViaAPI(data)** - Создание инцидента через API
6. **cy.createCaseViaAPI(incidentId, data)** - Создание дела через API
7. **cy.uploadFile(selector, filePath)** - Загрузка файла

### Конфигурация

- **Framework**: Cypress 15.7.0
- **Язык**: TypeScript
- **Frontend URL** (`baseUrl`): http://localhost:5173
- **Backend URL** (`apiUrl`): http://localhost:8081
- **Timeout**: 10 секунд
- **Retry**: 2 попытки в headless режиме

**Важно**: Cypress разделяет URL для фронтенда и бэкенда:
- `baseUrl` используется для открытия страниц (`cy.visit()`)
- `apiUrl` используется для прямых API запросов (`cy.request()` в командах)

Это позволяет тестам корректно работать с SPA приложением, где фронтенд и бэкенд работают на разных портах.
