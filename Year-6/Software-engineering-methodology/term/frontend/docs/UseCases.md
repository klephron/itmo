**UC №1: Обработка вызовов (FR 3.1.1)**
Диспетчер регистрирует вызов от гражданина, создает дело с автоматическим назначением ресурсов.

**UC №2: Работа с уликами, анализами (FR 3.1.7)**
Андроид-следователь собирает улики, офицер проверяет и подтверждает их достоверность.

**UC №3: Формирование шаблона отчета (FR 3.1.10)**
Система формирует шаблон отчета с данными дела, офицер дополняет и сохраняет его в ЦБД.

**UC №4: Уведомление участников дела об изменениях (FR 3.1.12)**
Система автоматически уведомляет всех участников при изменении статуса дела.

**UC №5: Автоматическое назначение ресурсов (FR 3.1.2)**
Система формирует рекомендованный состав отряда на основе типа дела и доступности ресурсов.

**UC №6: Предоставление доступа к делу (FR 3.1.3)**
Ответственный предоставляет или отзывает доступ участникам с определением их ролей.

**UC №7: Корректировка назначения ресурсов (FR 3.1.4)**
Диспетчер/офицер изменяет состав отряда после автоматического назначения.

**UC №8: Ролевой доступ (FR 3.1.5)**
Администратор управляет индивидуальными разрешениями пользователей.

**UC №9: Чтение данных по делу из Системы (FR 3.1.6)**
Участники просматривают сведения о деле согласно своим правам доступа.

**UC №10: Логирование (FR 3.1.8)**
Фиксация технических и аудиторных событий для последующего анализа.

**UC №11: Чтение данных Системой по делу из ЦБД (FR 3.1.9)**
Пользователь запрашивает файлы (отчеты, изображения улик) из центральной базы данных.

**UC №12: Сохранение отчетов Системой в ЦБД (FR 3.1.11)**
Система валидирует и сохраняет подписанный отчет в ЦБД.
